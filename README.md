# NBA Player Prediction

A machine learning system designed to forecast NBA player performance in upcoming games.

## Goal

The system will use historical player performance, matchup information, team context, injuries, lineups, betting data, and other pre-game information to predict player statistics.

## Planned Predictions

* Points
* Rebounds
* Assists
* Minutes
* Three-pointers made
* Steals
* Blocks
* Turnovers

## Planned Technologies

* Python
* Pandas
* PostgreSQL
* Scikit-learn
* XGBoost
* FastAPI
* Streamlit
* Git/GitHub
