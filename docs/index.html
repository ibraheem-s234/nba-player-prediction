    How it works

    The engine predicts a player's points, rebounds, assists, made threes and minutes for his next game. Every number on this site comes from a pipeline that can be rerun end to end from the project's GitHub repository.

    The pipeline

    1. CollectEvery regular-season box score from 2021-22 to 2025-26 is downloaded from stats.nba.com with nba_api: 131,291 player-games across 6,150 games.
    2. Clean and validateDates are typed, home/away and opponent are derived, and every game is checked for exactly two teams and no duplicate rows. Ten neutral-site games (Mexico City, Paris, NBA Cup semifinals) are kept with no home team rather than given a fake one.
    3. StoreA normalized PostgreSQL database with four tables (teams, players, games, player box scores) and a view of team totals. Foreign keys and a check constraint reject impossible rows.
    4. Engineer features63 inputs per player-game: recent form over 3, 5 and 10 games, season averages, volatility, usage, rest, opponent defence and pace, and the minutes missing from each lineup.
    5. Train and compareTwo baselines, ridge regression, a random forest and gradient boosting, tuned on 2024-25 and scored once on 2025-26.
    6. ProjectThe final models, retrained on all five seasons, project every active player against all 29 possible opponents, home and away.

    No peeking at the answer

    The rule behind every feature: a prediction for game N may only use games 1 through N−1. In code this is a shift(1) before each rolling average. An automated test rewrites the results of one date's games, rebuilds all 63 features, and fails if any feature on or before that date changes. Seasons are split by time, never at random, so the model is always tested on games that happened after everything it learned from.

    What the results say

    Limits

    Box scores only record players who played, so absences are measured after the fact. In live use they would come from the official inactive list released before tip-off. Projections carry each player's 2025-26 form and team forward, so they cannot see off-season trades, signings or injuries. Betting lines and play-by-play data are not used.
